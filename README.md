## Co wyróżnia Horyzont

- **Horyzont Focus** (`Ctrl+K .`): przygasza kod poza funkcją, w której pracujesz, chowa panele i wycisza powiadomienia.
- **Ślady edycji**: przy numerach linii widać, gdzie ostatnio pisałeś, a ślad blednie z czasem.
- **Kontekst per gałąź git**: po `git checkout` wracają karty, układ i breakpointy z tej gałęzi.
- **8 wbudowanych motywów**: Night, Dawn, Abyss (OLED), Ember, Moss, Fjord, Paper i Mist.
- **Prywatność i szybkość**: telemetria wyłączona, bez eksperymentów online, a rozszerzenia z Open VSX.
- **Automatyczne aktualizacje** z GitHub Releases.

## Instalacja

| System | Plik |
|---|---|
| Windows (x64) | `HoryzontUserSetup-x64-<wersja>.exe`, aktualizuje się sam |
| Linux (x64) | `.tar.gz`: rozpakuj i uruchom `bin/horyzont` |
| macOS (Apple Silicon) | `.zip`, za pierwszym razem otwórz prawym przyciskiem myszy → Otwórz |

Szczegóły zmian, budowania i wydań: [HORYZONT.md](HORYZONT.md).
